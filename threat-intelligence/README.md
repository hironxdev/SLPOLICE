# SL-CERT Cyber Threat Intelligence Dashboard

A production-ready monitoring and intelligence system focused on Sri Lankan cyber-security situational awareness.

## 🚀 Features

- **Real-time Attack Visualization**: Live Source-to-Destination mapping with severe incident rippling.
- **Sri Lanka Focus Mode**: Dedicated telemetry for regional incoming/outgoing threats.
- **Cyber Simulation Engine**: Realistic data generation mixed with intelligence feeds.
- **Operational Command UI**: High-end industrial aesthetic using Tailwind + Framer Motion.

## 🧱 Setup Instructions

### 1. Prerequisites

- Node.js 18+
- npm

### 2. Backend Setup

```bash
cd threat-intelligence/backend
npm install
npm run dev
```

The backend will start on `http://localhost:5050`.

### 3. Frontend Setup

```bash
cd threat-intelligence/frontend
npm install
npm run dev
```

The dashboard will be available at `http://localhost:3000`.

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, Tailwind CSS, Lucide Icons, Framer Motion.
- **Backend**: Node.js, Socket.io, Express.
- **Intelligence**: Simulation Engine + Mock Threat Feed ingestion.
